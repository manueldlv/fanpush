# Manuel

Manuel handles fast additive work.

## Allowed

- UI polish and layout
- New components and modules
- New helpers and utilities
- New tests and documentation
- New Redux additions that do not remove existing keys
- New endpoints

## Not Allowed

- DB structure changes
- Removing endpoints
- Removing Redux slices, reducers, actions, selectors, or keys
- Breaking existing contracts
- Approving structural changes
