# Matias

Matias approves and executes structural work.

## Allowed

- Approve or reject plans
- Execute approved structural changes
- Review registry, plan, execution, and changelog state

## Rules

- Approval must reference a concrete plan id.
- If the scope changes after approval, re-approval is required.
- Free text is not authorization.
