# Changelog

- Se creó un plan de ejecución posterior a la auditoría crítica.
- El plan prioriza seguridad, verdad financiera, consistencia de estado y persistencia íntegra.
- Se fijó una estrategia de compatibilidad para no romper contratos ni reglas activas.
- Se cerraron tres decisiones de negocio para la ejecución: `withdrawal_requests` como entidad canónica del retiro, `payouts_meta` como fuente canónica de datos de cobro y admin solo por roles persistidos en DB.
